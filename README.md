# Funk-Flitzer

Eine selbstständig bearbeitbare Making-Lernstraße mit WILMA-Tüftelbausteinen und micro:bit.

In sieben Doppelstunden entwickeln Teams ein rollendes Fahrgestell, erproben Ein- und Zwei-Motor-Antriebe, bauen eine Schaltersteuerung und programmieren schließlich eine Funkfernsteuerung mit zwei micro:bits. Jede Etappe führt von einer eigenen Idee über Prototyp und Test zu einer begründeten Verbesserung.

## Lernstraße

Die fertige Website liegt im Ordner `dist`. GitHub Pages veröffentlicht diesen Ordner automatisch über den Workflow in `.github/workflows/pages.yml`.

## Inhalte

- sieben aufeinander aufbauende Etappen
- echte Praxistests und dokumentierte Verbesserungen
- Teamrollen und gestufte Hilfen
- MakeCode-Blockbaupläne für Fahrzeug und Funksteuerung
- Making-Finale als Liefer-Challenge
- Fortschrittsspeicherung im Browser des Team-iPads
